# ExcelIA_SaraLuciaRiosChavez
Este proyecto consiste en un análisis de ventas mensuales realizado en Excel.
Datos simulados de ventas por mes para practicar análisis y gráficos.
Herramientas usadas
- Excel
- Gráficos manuales
- Fórmulas básicas (PROMEDIO, MAX, MIN)
como resueltado se observó un aumento progresivo en las ventas y el último trimestre fue el más fuerte.
